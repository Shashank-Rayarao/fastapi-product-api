# fastapi-product-api

A backend REST API built using Python, FastAPI, MySQL, and SQLAlchemy
for managing product information through CRUD operations.

## Features

- Create products
- Retrieve all products
- Retrieve a product by ID
- Update product information
- Delete products
- MySQL database integration
- SQLAlchemy ORM
- Request validation using Pydantic
- Interactive API documentation using Swagger UI

## Tech Stack

- Python
- FastAPI
- MySQL
- SQLAlchemy
- Pydantic
- Uvicorn
- PyMySQL
